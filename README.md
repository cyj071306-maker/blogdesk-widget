# 지원금 진단 위젯 (GitHub Pages 배포용)

블로그 글에 iframe으로 붙이는 "나에게 맞는 지원금·제도 찾기" 위젯입니다.
- 이 저장소에는 **index.html 한 파일만** 공개합니다(작업실 앱 소스는 비공개).
- 입력은 브라우저 안에서만 계산하고 저장·전송하지 않습니다(외부 요청 차단 CSP 포함).
- 참고용 안내이며, 실제 자격은 보조금24·복지로·담당 기관에서 확인해야 합니다.

갱신: 작업실(blogdesk) `/widget`에서 규칙 확인 → [빌드] → `npm run widget:export` → 이 폴더에서 `git add -A && git commit -m "위젯 갱신" && git push`.
